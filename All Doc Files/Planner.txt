 IAM Role

 AN IAM Role is set of permissions that anyone (or anything) can assume temporarily to do a specific task.
 OR
 temporary identity with permissions that an AWS service, application, or user can assume to access other AWS resources.


 Without IAM Role, if spring boot app wants to integrate with S3 bucket or any other services, it required AWS Access key , AWS secret key. But its not recommendded as credentials can exposed accidently.

 Spring Boot application
       ↓
AWS Access Key
AWS Secret Key
       ↓
S3

But if we use IAM role, AWS automatically provides temporary credentials to the EC2 instance.
Spring Boot ->  EC2 ->  IAM Role -> S3
