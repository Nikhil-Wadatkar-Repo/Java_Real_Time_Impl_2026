======================
Chat Memory Advisors
======================

=> In Spring AI, by defalt ChatClient is not remembering our previous conversation with LLM.

=> In Spring AI, Chat Memory Advisors are used to make the AI to remember previous questions and answers in a conversation and respond in the context-aware, just like ChatGPT.

=> A Chat Memory Advisor is a middleware component that

		- store user questions

		- store AI model responseses

		- Inject past conversation into every new prompt automatically



What is Prompt Engineering ?
==============================

=> It is the process of asking questions to AI models.

=> Prompt Engineering is the skill of designing clear, effective instructions (prompts) to get the best possible output from AI models like OpenAI, Gemini, OllaMa, or Claude.

Example : 

// Poor Prompt
Prompt-1 : Explain JAVA

// Good Prompt
Prompt-2 : Explain java for beginner in simple english with real-world examples in 10 points. 


=> Key elements of a good prompt

		1. Role  (Ex: Act as a java instructor)

		2. Task (Ex: Explain SpringBoot)

		3. Context (Ex: For java freshers)

		4. Format (Ex: Use bullet points with examples)

		5. Constraints (Ex: With in 200 words)

@Service
public class OpenAIService {

	// spring ai interface (impl class will be provided by LLM provider)
	private ChatClient chatClient;

	/*
	public OpenAIService(ChatClient.Builder builder) {
		this.chatClient = builder.build(); // state less client
	}
	*/
	
	// Making chatclient as statefull
	public OpenAIService(ChatClient.Builder builder, ChatMemory chatMemory) {
		this.chatClient = builder.defaultAdvisors(MessageChatMemoryAdvisor.builder(chatMemory).build()).build();
	}
	
	public String askAnything(String question) {
		return chatClient.prompt().user(question).call().content();
	}
	

	public String getTravelGuidance(String place, String month, String language, String budget) {
		
		PromptTemplate promptTemplate = new PromptTemplate("Welcome to the {place} travel guide!\n"
				+ "If you're visiting in {month}, here's what you can do:\n" + "1. Must-visit attractions.\n"
				+ "2. Local cuisine you must try.\n" + "3. Useful phrases in {language}.\n"
				+ "4. Tips for traveling on a {budget} budget.\n" + "Enjoy your trip!");
		
		Prompt prompt = 
				promptTemplate.create(Map.of("place", place, "month", month, "language", language, "budget", budget));
		
		return chatClient.prompt(prompt).call().chatResponse().getResult().getOutput().getText();
	}
}

A Vector Store DB is a database designed to store and search data in the form of vectors (numbers) instead of rows and columns.

Text, images, audio, and code cannot be directly compared by meaning.

=============
What is RAG
=============

=> RAG stands for Retrieval-Augmented Generation

=> RAG is an AI architecture that combines "Vector search + LLM generation"

=> Instead of asking the LLM to answer from memory, we can:

		- Retrieve relevant data from a vector DB
		- Augment the prompt with that data
		- Let the LLM generate an answer


======================
Why RAG is required ?
======================

=> To overcome below challenges of LLMs we are using RAG

		- LLMs Don't have access to private data / latest data

		- LLM will have fixed knowledge (Training Cutoff)

=============================
How to implement RAG System	
=============================

Step-1 : Data Ingestion

			 - Collect data in the form of PDFs, Word files, txt files, websites, DB records
			 - Convert text -> embeddings
			 - Store data in vector db

Step-2 : User Query			 

				- User asks a question (Ex: What is JAVA)
				- Query will be converted into embedding

Step-3 : Retrieval				

				- Vector DB finds most similar documents
				- Returns top relevant chunks

Step-4 : Generation

			  - Retrieved Content + User Question
			  - Sent to LLM (GPT, LLaMMA, Gemini)
			  - LLM Generates accurate answer

Step-1 : Setup pinecone account (free of cost)

		URL : https://www.pinecone.io/

Step-2 : Generate API Key and note it down

Step-3 : Create Index (database)

				Select Model : text-embedding-3-small
				Select Dimensions : 1536

Step-4 : Create SpringBoot application with below dependencies

					- web-starter
					- spring-ai-starter-open-ai
					- spring-ai-advisors-vector-store
					- vector-store-pinecone

Step-5 : Keep data files in 'src/main/resources/'	folder (Ex: spring-notes.txt)

Step-6 : Configure Open AI & Pinecone keys in "properties/yml" file

Step-7 : Create a Data Loader class to load our data into Vector Store DB.

Step-8 : Create Service class with business logic (RAG + LLM Integration)

Step-9 : Create Rest Controller with Http Method

Step-10 : Run the application and test it using Postman.
